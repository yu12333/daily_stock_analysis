# 细分行业分析（Customized Only）功能说明

## 功能概述

新增 `customized-only` 模式，专注于申万三级行业（细分行业）涨跌榜分析，作为**独立报告**发送，提供更细粒度的板块主线洞察。

## 报告结构

### Full 模式（完整分析）包含 3 个独立报告：
1. 📈 **个股分析报告** - 你的自选股分析
2. 📊 **大盘复盘报告** - 大盘指数 + 板块主线（申万一级）
3. 📋 **细分行业报告** - 申万三级行业涨跌榜 Top 10（新增）

### 发送频率：
- **个股分析 + 大盘复盘**：每天 12:00 和 18:00（北京时间）
- **细分行业报告**：交易期间 9:25-14:55，每30分钟一次

## 主要特性

### 1. 细分行业涨跌榜
- **数据来源**：东财细分行业板块、申万二级行业、新浪行业板块（多源 fallback）
- **展示内容**：领涨/领跌 Top 10 细分行业
- **智能分类**：自动将细分行业归类到大类（科技、医药、消费、金融、新能源、制造、地产、周期、农业、传媒等）

### 2. 板块主线总结
- **领涨主线**：自动识别领涨板块的主要大类
- **领跌主线**：自动识别领跌板块的主要大类
- **市场风格判断**：分析成长/价值风格切换

### 3. 自动定时推送
- **交易期间**：A股交易日 9:25-15:00，每30分钟推送一次
- **覆盖时段**：
  - 上午盘：9:25, 9:55, 10:25, 10:55, 11:25
  - 下午盘：13:05, 13:35, 14:05, 14:35, 14:55

## 使用方式

### 方式1：GitHub Actions 手动触发
1. 进入 Actions 页面
2. 选择「每日股票分析」workflow
3. 点击「Run workflow」
4. 在「运行模式」下拉菜单中选择「customized-only」
5. 点击「Run workflow」按钮

### 方式2：自动定时执行
- 新增的「细分行业分析（每30分钟）」workflow 会在交易期间自动执行
- 无需手动配置，自动遵循 A 股交易日历

### 方式3：命令行执行
```bash
# 仅运行细分行业分析
python main.py --customized-only

# 强制运行（跳过交易日检查）
python main.py --customized-only --force-run
```

## 修改的文件

### 数据层
1. **data_provider/akshare_fetcher.py**
   - 新增 `get_sw_third_sector_rankings()` 方法
   - 支持多数据源 fallback：东财细分行业 → 申万二级 → 新浪行业

2. **data_provider/base.py**
   - 在基类中添加 `get_sw_third_sector_rankings()` 接口定义
   - 在 `DataFetcherManager` 中添加调用方法

### 分析层
3. **src/market_analyzer.py**
   - `MarketOverview` 类新增 `top_sw3_sectors` 和 `bottom_sw3_sectors` 字段
   - 新增 `_get_sw3_sector_rankings()` 方法获取数据
   - 新增 `_build_sw3_sector_block()` 方法渲染报告
   - 支持智能行业分类和主线总结

### 报告层
4. **src/core/market_review.py**
   - 新增 `run_customized_review()` 函数
   - 支持 `DSA_CUSTOMIZED_ONLY` 环境变量

### 入口层
5. **main.py**
   - 新增 `--customized-only` 命令行参数
   - 添加对应的处理逻辑

### Workflow 层
6. **.github/workflows/00-daily-analysis.yml**
   - 在 mode 选项中添加 `customized-only`
   - 添加对应的处理逻辑

7. **.github/workflows/01-customized-sector.yml**（新增）
   - 每30分钟自动执行的 workflow
   - 覆盖 A 股交易期间 9:25-15:00

## 注意事项

1. **数据源可用性**：细分行业数据依赖外部 API，可能受网络和限流影响
2. **交易日历**：自动遵循 A 股交易日历，非交易日跳过执行
3. **通知配置**：需要配置至少一个通知渠道才能接收推送
4. **执行频率**：每30分钟一次的频率可能对某些免费 API 造成压力，建议使用付费数据源
